Install Blackout Kit

Choose the install path that matches your platform and trust needs.

Windows packaged app

Download the latest packaged executable from GitHub Releases:

https://github.com/kiacoder/blackout-kit/releases

Windows source install

git clone https://github.com/kiacoder/blackout-kit.git
cd blackout-kit
pip install -r requirements.txt
python blackout.py version
python blackout.py bins
python blackout.py bins download

Linux source/runtime install

python3 -m pip install -r requirements.txt
mkdir -p bins
chmod +x bins/blackout-engine
python3 blackout.py version

Linux requires the managed runtime asset in bins/blackout-engine and currently supports only xray, tun, hysteria2, and tuic.

After install

python blackout.py doctor
python blackout.py route
python blackout.py ready xray
python blackout.py connect

See the User Guide for the full first-run flow.
