================================================================================

Invalid URL Scheme:
  ✗ Invalid threat feed URL: http://example.com/feed...
  💡 URL must start with https:// or a proxy protocol (vmess, vless, trojan, hysteria2)
  Examples:
    blackout config add https://example.com/sub
    blackout config add vmess://...

Invalid Blocklist Source Name:
  ✗ Invalid blocklist source name: 'bad-name!'
  💡 Source name must contain only letters, numbers, dots, hyphens, and underscores
  Examples:
    adblock_easylist
    phishing-domains
    ads.list

Invalid Blocklist URL:
  ✗ Invalid blocklist URL: http://example.com/list...
  💡 URL must start with https:// and resolve to a global IP (not localhost or private IP)
  Examples:
    https://easylist-downloads.adblockplus.org/easylist.txt
    https://phishing.army/download/phishing_army_blocklist.txt
